# indubharkavi.github.io

Personal site for Dr. Indu Bharkavi S.K — oral pathologist, researcher and academic leader.

Static HTML, no build step. Served by GitHub Pages from the repository root.

```
index.html        Home
about.html        Background, education, competencies
experience.html   Appointments, admin roles, clinical practice
research.html     Publications and research areas
contact.html      Contact details and CV download
assets/style.css  Single stylesheet
assets/Indu-Bharkavi-CV.pdf  Downloadable resume (placeholder)
```

To preview locally: `python3 -m http.server 8000`
